# PO/GRN multi-select prototype

Interactive prototype of selecting multiple POs and GRNs on one bill, across the four fetch models (Zoho-style PO and PO+GRN, Logic ERP/Petpooja GRN, Rista PO then GRN).

Open `index.html` in a browser. It is a single self-contained file with sample data only. Nothing is saved or sent anywhere.

Behaviour is documented in the "PO / GRN fetch from ERP" doc (idea PB-371).
